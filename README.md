# رزومه و نمونه‌کارهای فائزه نوری

قالب فارسی و راست‌چین با HTML، CSS و JavaScript؛ آماده انتشار رایگان در GitHub Pages.

## انتشار
1. در GitHub یک repository جدید بساز.
2. همه فایل‌های این پوشه را در ریشه repository آپلود کن؛ `index.html` باید در ریشه باشد.
3. به **Settings → Pages** برو.
4. در بخش Build and deployment گزینه **Deploy from a branch** را انتخاب کن.
5. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کن.
6. پس از چند دقیقه، آدرس سایت در همان صفحه ظاهر می‌شود.

## قبل از انتشار
- در `index.html` مقدار `your-email@example.com` را با ایمیل واقعی خودت جایگزین کن.
- سطح مهارت‌ها و متن سوابق را دقیق و واقعی تنظیم کن.
- سه تصویر نمونه در پوشه `assets` تصاویر گرافیکی ساخته‌شده برای همین قالب هستند؛ هرکدام را می‌توانی با تصویر پروژه واقعی خودت جایگزین کنی. نسبت تصاویر 3:2 است.
- برای جایگزینی تصویر، فایل جدید را در `assets` قرار بده و آدرس `src` تصویر را در `index.html` تغییر بده.

## نکته
GitHub Pages فایل‌های ایستا را منتشر می‌کند و PHP یا پایگاه داده MySQL را اجرا نمی‌کند. این قالب برای نمایش رزومه و نمونه‌کار مناسب است؛ فرم تماس از لینک ایمیل استفاده می‌کند و پیام‌ها را در پایگاه داده ذخیره نمی‌کند.
